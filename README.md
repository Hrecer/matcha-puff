# 抹茶泡芙

基于 **Tauri 2** 的 Windows 桌面工具应用。五个界面：**工作台**（全局搜索台）、**专注**（番茄钟）、**时间**、**白噪音**、**工具**（53 个内置插件）。

没有账号，没有埋点，所有数据和计算都留在本机。

---

## 五个界面

| 界面 | 定位 |
|---|---|
| **工作台** | 搜索台，搜工具 / 搜索源 |
| **专注** | 番茄钟 + 任务 / 习惯 / 统计 / 四象限 / 收件箱 |
| **时间** | 日历、时钟、计时器、秒表、时间差、人生 |
| **白噪音** | 35 段内置环境声，可混放、收藏、自制合集 |
| **工具** | 53 个内置工具，按五大分类浏览 |

---

## 工作台

整个应用的入口：从侧栏「工作台」进入，或点托盘菜单里的「显示窗口」。

- **输入框搜全部**：左栏是工具，右栏是搜索源（用 Bing / 百度 / Google 等直接搜当前输入），点一下就交给系统浏览器；
- **收藏与最近**：星标过的工具进收藏页，打开过的按时间倒序进最近页，都按网格铺开；
- **分类浏览**：不搜索时按「系统运维 / 编辑工具 / 编程工具 / 设计工具 / 生活常用」逐层展开，吸顶分类条可直接跳；
- **右侧状态面板**：实时显示当前时间、日期，以及正在进行的专注（阶段、剩余时间、进度、关联任务）。

搜索源可以自己加、自己改、自己排顺序，在设置里维护。

## 专注

番茄钟是这里的核心，计时权威放在 **Rust 侧** —— 关掉窗口、切到别的页面，回来时间照样准，不会因为前端被节流而跑偏。

围绕计时还有一整套自己的数据：

- **任务**：带截止时间倒数，可以挂到某次专注上；
- **习惯**：按周期重复（每天 / 工作日 / 法定节假日 / 每周某天 / 每年），显示下次到期倒数；
- **四象限**：按重要 / 紧急规划任务；
- **统计**：专注时长、活跃天数、连续天数与任务完成情况；
- **收件箱**：随手记下来、之后再归类的临时条目；
- **日历**：按天看专注记录，标出节假日与调休，支持切换年月。

另外还有个按需打开的置顶小挂件：默认隐藏，可从专注页标题、专注芯片或托盘菜单打开，打开后固定在主屏顶部。

## 时间

六个页签，都是围绕「时间」本身的小工具，共享同一个页面：

**日历** · **时钟** · **计时器** · **秒表** · **时间差** · **人生**

「日历」带农历、节气与法定节假日 —— 年视图可以在「日历 / 节气 / 假期」之间切换，节气带七十二候说明，假期区分放假与调休补班；这些数据拉一次存在本地，之后断网也能判定。

「人生」把剩余时间量化成可视化的格子，一眼看到已经用掉多少。

## 白噪音

- **声音库**：35 段内置声音，分自然 / 日常 / 动物 / 天气 / 生活五类，可收藏、筛选、搜索，正在播放的卡片有三柱律动条；
- **合集**：把当前正在播的声音存成一套，点标签能跳回声音库并闪烁定位；支持整卡拖动排序；
- **自定义**：导入本地 mp3 / wav / ogg / m4a，音频存进 IndexedDB，和内置声音一样参与收藏、分类、合集。

滚动位置按锚点记忆：切页签、切页面都回到原处，重启才归零。

## 工具

53 个内置工具，落在五大分类下（系统运维、编辑工具、编程工具、设计工具、生活常用，共 23 个子分类）。工具窗口是独立子窗口，可以单独摆放。

工具不是网页快捷方式 —— **每个工具是一个 TypeScript 插件模块**，在 `packages/tools/<工具名>/` 里用一份 manifest 定义 ID、名称、描述、参数 Schema、权限声明和界面元数据，业务逻辑再单独实现。导航、搜索、详情页、参数表单全部由这份声明派生，不重复维护。

新增一个工具就是加一个目录，然后 `pnpm plugin:index` 重新生成注册清单。

## 其他

**插件中心**、**设置**、**关于** 都挂在侧栏底部：插件中心可以搜、筛、批量开关每个工具（总开关 / 是否在界面出现）；设置里管启动默认页、开机自启、搜索源维护、数据清空；托盘常驻、单实例、开机自启都是标配。

## 目录

```
.
├── desktop/                唯一的应用：src/ 前端界面，src-tauri/ Rust 后端，
│                           public/ 内置音频
├── packages/
│   ├── tool-contracts/     插件类型、统一结果模型、执行上下文
│   ├── tool-runtime/       工具注册表与统一执行内核
│   ├── tool-settings/      工具开关与偏好的持久化
│   ├── tools/              内置工具插件（每个目录一个）
│   └── pomodoro-core/      番茄钟领域逻辑
└── scripts/                仓库级脚本：插件清单生成与校验
```

★ = 生成物，可随时删除、随时重建（不进版本库）：
   desktop/frontend/next/（前端产物，唯一输出目录）
   desktop/src-tauri/target/（Rust 构建缓存）
   desktop/src-tauri/gen/（Tauri 生成的权限 schema）
   各处 node_modules/

工具落哪儿：**业务写在 `packages/tools/<工具>/`，界面只在 `desktop/src/pages/tools/` 里做自定义视图**，其余由清单驱动。

## 开发与构建

**环境**：Node ≥ 20、pnpm、Rust（MSVC 工具链）、Windows 10/11 x64。

在仓库根目录（pnpm workspace）：

```
pnpm install
pnpm packages:build     # 先构建共享包

pnpm desktop:dev        # 桌面应用开发服务器（Vite，5183）
pnpm desktop:build      # 构建前端产物 → desktop/frontend/next
pnpm desktop:bundle     # 出安装包（先构建前端，再 tauri build --bundles nsis）

pnpm typecheck          # 全工程类型检查
pnpm test               # 单元测试与集成测试
pnpm check              # 类型检查 + 测试 + 插件定义校验

pnpm plugin:index       # 新增/改动工具后重新生成插件注册清单
pnpm plugin:validate    # 校验所有插件定义
```

前端产物只有 `desktop/frontend/next` 一个落点（Tauri 的 `frontendDist` 指向 `../frontend`），不会出现第二份副本。

后端单独构建（在 `desktop/src-tauri/` 下）：`cargo build --release`，构建完成后运行 `cargo run --release` 启动应用。

> `frontendDist` 会被编译进可执行文件 —— **改了前端就要重新构建后端**，否则界面不更新。

## 数据都在哪

| 内容 | 位置 |
|---|---|
| 应用数据库、WebView 数据 | `%LOCALAPPDATA%\com.matchapuff.desktop\`（`matcha.db`、`EBWebView\`） |
| 工具开关 | `~/.matcha-puff/settings.json`（可用 `MATCHA_PUFF_SETTINGS` 覆盖） |
| 自定义白噪音音频 | 浏览器 IndexedDB（`matcha-puff-noise`） |
| 出厂种子数据 | 源码 `desktop/src-tauri/resources/seed.sql`，编译期打进 exe，首次运行时建库 |

**数据库没有迁移机制**：`seed.sql` 只建默认搜索源与专注的两张表，编译期 `include_str!` 进可执行程序。工具目录在 `packages/tools` 的 manifest 里，分类在 `desktop/src/data/categories.json`。库文件不存在就整库重建；库文件损坏（缺少种子表）就备份成 `matcha.db.broken-*` 再重建。改结构 = 改这个 SQL 文件，改完删掉本地 `matcha.db` 即可。

种子用文本维护，加一个默认搜索源就是多一行 `INSERT`，改了什么在 diff 里看得见。dev 下若数据目录被解析到工作区内，会自动改写到系统临时目录，避免运行时数据库被误提交。

## 设计原则

- **单一业务逻辑来源**：每个工具只实现一次，界面与搜索都走同一份。
- **单一调用入口**：所有调用经过 Tool Runtime，调用方不得直接执行插件逻辑。
- **单一工具定义**：ID、名称、描述、参数 Schema、权限声明只维护一份，其余清单由此生成。
- **单一产物目录**：前端只往 `frontend/next` 打，不留第二份等价副本。
- **数据不离开本机**：没有账号，没有埋点，网络只在工具明确需要时才用。
